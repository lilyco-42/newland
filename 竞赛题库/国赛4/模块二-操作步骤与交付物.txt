■ 2-2 设备无线通讯控制系统（两块黑色 ZigBee 开发板 A、B）
  硬件：板 B 装继电器并连接风扇；点击板 A 的 SW1 可控制板 B 风扇启动/停止。
  实现要点（Z-Stack 工程）：
    - 板 A：SW1 下降沿触发 → 通过无线发送开关命令（帧中携带 0x01 开 / 0x00 停）
    - 板 B：AF 收到命令 → 置继电器引脚高低电平 → 风扇启/停
  交付：完整工程代码保存到 U 盘“提交资料\模块二\题2”目录【代码骨架见 2-2_2-3_嵌入式代码.txt】

■ 2-3 计数器系统开发（NB-IoT 模块 + 液晶屏）
  任务：通电 LED2 灭；液晶屏显示“计数器数值：N 结果：Y”(N 为自然数)；
        Key2 → N 减 1；Key3 → N 加 1；Key4 → 保存 N 到 Flash，LED2 亮 1 秒后灭；
        断电重启后 N 显示最后一次保存在 Flash 中的数值。
  实现要点：读按键 → 更新 N 与结果 Y（Y 由公式代入 N 得出，公式见任务书附图）→ 刷新液晶屏；
        Key4 时写 Flash（如 CC2530 的 XDATA 段 Flash 读写），LED2 延时 1s 灭。
  交付：完整工程保存到“提交资料\模块二\题3”【代码骨架见 2-2_2-3_嵌入式代码.txt】

■ 2-4 行人监控系统开发（Android，云服务系统读传感/控执行器）
  逻辑：行程开关（轮式）默认闭合 → 红绿灯按钮为绿灯；摇动转臂断开 → 红灯。
        红灯时多层指示灯仅红灯亮；绿灯时仅绿灯亮；
        绿灯状态显示绿灯放行图（红外对射报警也不变）；
        红灯 + 红外不报警 → 红灯禁止图，报警灯灭；红灯 + 红外报警 → 闯红灯图，报警灯报警；
        退出 app 前将红灯、绿灯、报警灯全部熄灭。
  发布：程序命名“行人监控”发布到移动互联终端；工程源码另存为“行人监控系统源码.rar”
  提示：数据经 nlecloud 云 API（GET 传感器值 / POST 执行器控制），参考源码目录 nle_cloud.py 的接口写法。
