# 智能商超系统

## 功能说明
1. 使用超高频RFID设备，读取三个超高频标签（客人A、B、C）的消费情况。
2. 存储客人"超高频标签卡号、姓名、消费额"。
3. 随意读取任意一张超高频标签，将该客人的消费额显示在界面上，
   并利用TTS语音播报功能播报金额。

## 预置客户数据
| 姓名 | 消费额(元) | 标签卡号 |
|------|-----------|----------|
| 客人A | 24 | E280116060000209A000000001 |
| 客人B | 30 | E280116060000209A000000002 |
| 客人C | 27 | E280116060000209A000000003 |

## 运行环境
- Python 3.x
- TTS 语音：需要安装 pyttsx3 或 pywin32（SAPI）
  ```
  pip install pyttsx3
  ```
  若都不可用，程序会尝试调用 Windows SAPI 播报。

## 使用方法
1. 将本目录拷贝到终端工作站。
2. 运行：`python supermarket.py`
3. 点击"开始读取"，将超高频标签靠近读卡器。
4. 界面显示该客人的标签卡号、姓名、消费额，同时 TTS 播报金额。

## 硬件配置
- RFID 读取器：超高频(UHF)读卡器，连接终端（USB/串口）。
- 标签：在标签纸上分别标注"客人A、客人B、客人C"并贴于对应标签。
- 接入真实读卡器时，修改 supermarket.py 中 `SerialRFID` 的端口参数，
  并按厂商SDK实现 `read_tag()` 返回标签EPC。

## 未登记标签的处理
程序会提示"未登记客户"，不影响系统运行。
