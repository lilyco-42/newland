# 运输数据监控系统（窗帘控制）

## 功能说明
1. 通过无线采集方式获取云平台温湿度、光照数据。
2. 点击"开始"后实时获取并显示云平台的温湿度、光照值。
3. 光照感应控制：
   - 用手遮住光照传感器（光照值低于阈值）→ 同时打开运输系统中的灯和风扇，
     风扇动画启动，灯为点亮状态。
   - 将手拿开（光照值恢复正常）→ 关闭灯和风扇，风扇动画停止，灯为熄灭状态。

## 运行环境
- Python 3.x（芯片终端/Python 终端）
- 依赖库：仅标准库（tkinter 随 Python 自带）
- 可选库（TTS）：pyttsx3 或 pywin32

## 使用方法
1. 将本目录拷贝到终端工作站。
2. 运行：`python transport_monitor.py`
3. 登录云服务系统（竞赛提供的账号/密码）。
4. 点击"开始"按钮开始采集。
5. 用手遮挡光照传感器验证灯与风扇自动开启。

## 参数配置
点击"设置"可配置：
- 云服务地址（默认 https://api.nlecloud.com）
- 温度/湿度/光照/风扇/灯 的 ApiTag 标识
- 刷新间隔（秒）
- 光照阈值（光照值低于该值时开灯开风扇，默认20）

默认标识（需按实际云端设备修改）：
- 温度: m_Temp
- 湿度: m_Hum
- 光照: m_Light
- 风扇: m_Fan
- 灯:   m_Lamp

## 硬件
- 根据现场情况连接温湿度、光照传感器，及灯、风扇执行器。
- 所有数据经云平台转发，应用侧仅需联网。
