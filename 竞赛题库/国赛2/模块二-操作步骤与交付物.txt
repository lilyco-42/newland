【第2套·模块二 2-1 至 2-8】操作步骤与交付物清单
================================================

■ 2-1 物联网项目原型设计（Axure 串口调试工具）
  要求：串口 COM1~COM5；波特率 9600/19200/38400/115200/Other；
        数据位 5/6/7/8；校验位 奇/偶/None；停止位 1/1.5/2；
        默认状态 CLOSED、“发送”灰色；点击“打开串口”→ 串口非空验证
        （空值弹窗提示）；有值 → 状态变 OPENED、“发送”变黑色、
        “打开串口”变“关闭串口”；点击“关闭串口”→ CLOSED、发送变灰色、
        按钮恢复“打开串口”。
  交付：交互原型（本目录 2-1_串口调试工具\serial_debug.html 已按上述逻辑实现）；
        Axure 工程另存为“原型设计.rp”。
  提示：Axure 用下拉框 + 按钮交互样式 + 条件判断（text.length>0）实现。

■ 2-2 按键控制程序（1 个蓝色 ZigBee 节点盒）
  逻辑：通电 LED1/LED2 不亮；长按 SW1 → LED1 亮 LED2 灭；
        松开 → LED1、LED2 常亮；双击 → LED1 呼吸灯、LED2 灭；
        再次双击 → LED1 维持当前亮度、LED2 灭。
  交付：节点盒装 B-Q3、天线贴“E-1”、通电待评分；
        完整工程代码存 提交资料\模块二\题2。【代码骨架见 2-2_2-3_嵌入式代码.txt】

■ 2-3 LoRa 环境监控系统
  逻辑：采集温湿度光照（显示不带小数）；光照度 <100 lux → LED2 亮；
        USB 115200；网络调试工具默认 Hex；按压 SW2 → ASCII 传输，松开恢复 HEX。
  交付：LoRa 板贴“C-3”，USB 连工作站，网络调试工具接收显示；
        源码打包“LoRa环境监控系统.rar”。【代码骨架见 2-2_2-3_嵌入式代码.txt】

■ 2-4 远程监控应用开发（Android）
  逻辑：默认监控关闭（不显示自动设置信息）、路灯可手动开关；
        “开启监控系统”→ 连接摄像头显示实时画面 + 上下左右控制；
        开启状态：路灯默认 18:00 开、6:00 关，可修改设置并存储生效；
        “关闭监控系统”→ 断开连接、画面恢复背景图、自动设置隐藏、
        路灯关闭、恢复手动控制。
  复用：D:\源码\2-4_远程监控（Android 工程，可打开构建）。
  发布：程序命名“远程监控”发布到物联网应用开发终端；终端装到中间工位 B-Q3；
        工程源码打包“远程监控.rar”拷入 提交资料\模块二\题4。

■ 2-5 智能环境监控应用开发（Android，程序名“环境监控”）
  逻辑：通道设置参数页（参考 C-4-1.txt）；
        温湿度(C-Q3)、光照度(C-Q3)、ZigBee人体红外(C-Q4) 数据来自
        云服务系统最新上报，5 秒刷新；
        光照 <100 → 常亮绿灯开；温度 >27℃ → 风扇1 开；
        人体感应到人 → 绿灯+电视图片；无感应 → 延时 60 秒关绿灯、电视黑屏；
        执行器开关图片与工位设备状态同步。
  参数配置：本目录 2-5_智能环境监控\C-4-1.txt【已生成】
  发布：程序命名“环境监控”发布到物联网应用开发终端（未发布不得分）；
        终端装到中间工位 B-Q3；源码打包“环境监控源码.rar”。
  复用参考：D:\源码\2-4_环境监控（Android 工程，可按本套规则调整）。

■ 2-6 钻井深度监测功能开发（Python，工程代码已生成）
  目录：2-6_钻井深度监测\drilling_monitor.py + config.json
  逻辑：5 秒采样一次超声波数据并显示；“数据-时间”折线图仅显示最近 6 次；
        数据 ≥50cm → 频闪红灯亮（动画）；<50cm → 常亮绿灯亮（动画）；
        频闪红灯/常亮绿灯接联动控制器；不用云服务（用云不得功能分）；
        导出Excel：最近 20 条按记录时间倒序（时间、超声波数据两列）。
  发布：编译为“钻井深度监测”Python 应用，保存到
        提交资料\模块二\06钻井深度监测功能开发\；
        工程代码拷贝到 提交资料\模块二\钻井深度监测功能开发\。
  打包：pyinstaller -F -w -n 钻井深度监测 drilling_monitor.py

■ 2-7 门禁系统功能开发（Python，工程代码已生成）
  目录：2-7_门禁系统\access_control.py + config.json + nle_cloud.py
  逻辑：UHF 射频读写器读 RFID（经云服务系统获取）；
        云服务系统控制多层警示灯红灯（联动控制器）；
        红灯开关 → 红灯亮/灭 + 警告声 + 界面动图；
        每次读卡显示 RFID + 刷卡时间 + 刷卡人员图像（5 秒后消失）；
        刷卡记录按读卡时间倒序展示；导出Excel（时间、卡号两列，倒序）。
  发布：编译为“门禁系统”Python 应用，保存到
        提交资料\模块二\门禁系统功能开发\；工程代码拷贝到同一目录。
  打包：pyinstaller -F -w -n 门禁系统 access_control.py
