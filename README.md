# GZ038 物联网应用开发 · 备赛资料库

2023 年全国职业院校技能大赛高职组 GZ038「物联网应用开发」赛项备赛资料与全部源代码。
仓库按**赛题模块**组织：每个题目录内同时包含源码项目与当年提交资料。

## 目录结构

| 目录 | 内容 |
|---|---|

## 源码 ↔ 赛题题目对应表

目录名即赛题任务书中的真实题目名（GZ038 各套赛题模块二题2~7 题目不同）。
**嵌入式 C 工程为 CC2530/Z-Stack 风格 main.c + board.h，业务逻辑与协议字节表已闭环，板级 BSP 按现场工位板补全即可编译；应用类 Android 为 Gradle 骨架、Python 为 Tkinter/PyQt + nle_cloud.py，config.json 控制云/演示模式。**

## 说明

- 仓库为公开仓库，供备赛学习交流；源码已剔除 `__pycache__`、`build/`、`dist/`、`.venv/` 等生成物与本地路径配置（local.properties）。
- 嵌入式 C 工程无真机调试环境，板级初始化（时钟/引脚/外设）按赛项开发板 BSP 补全；业务逻辑、串口字节协议、传感器读数换算与阈值判定已按赛题要求闭环。
- Python 工程默认 `demo` 模式可脱机演示；接真机时把 `config.json` 的 `mode` 改 `cloud` 并填串口服务器/云平台地址即可。
