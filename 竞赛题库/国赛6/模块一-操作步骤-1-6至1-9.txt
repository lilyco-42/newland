■ 1-6 Windows系统维护（服务器防火墙规则 + 工作站网络命令）
  ① 配置“禁止工作站计算机访问本机任何程序或者端口，暂不启用此规则”：
     Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则
     → 规则类型：自定义（或“所有程序”）→ 协议和端口：所有协议/所有端口
     → 作用域：远程 IP 地址填工作站计算机 IP（如 192.168.0.x / 任意 IP）
     → 操作：阻止连接 → 配置文件：域/专用/公用 全勾选
     → 名称：禁止工作站访问；关键：取消勾选“立即启用此规则”！（暂不启用）
  ② 查看网络连接以及每一个网络接口设备状态：
     netstat -an          （查看网络连接）
     ipconfig /all        （查看各网络接口设备状态）
     （也可用：netsh interface ipv4 show interfaces）

■ 1-7 Ubuntu系统维护（虚拟机）
  ① 设置 IP：根据模块一“局域网各设备IP配置”，修改 netplan 配置并应用：
     sudo nano /etc/netplan/01-netcfg.yaml
       eth0: addresses: [192.168.0.x/24]; gateway4: 192.168.0.1; nameservers: 8.8.8.8
     sudo netplan apply
  ② 创建 test 文件夹：mkdir test
  ③ 修改权限 755：chmod 755 test

■ 1-8 数据库运维查询与优化（SQL Server，SSMS）
  ① 创建新数据库用户 dbUser，密码 abcd1234!@#$ ：
     SSMS → 服务器 → 安全性 → 登录名 → 新建登录名
     → 登录名：dbUser；SQL Server 身份验证，密码 abcd1234!@#$，
     取消“强制实施密码策略”可避免复杂度过高，直接确定
  ② 设置 dbUser 为系统管理员角色：
     双击该登录名 → “服务器角色”页 → 勾选 sysadmin
  ③ 设置数据库最大并发连接数为 10 ：
     SSMS 服务器属性 → “连接”页 → 勾选“最大并发连接数”并填 10 → 确定
