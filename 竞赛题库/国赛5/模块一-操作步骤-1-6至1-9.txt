二、1-7 Ubuntu服务器部署
  步骤：
  1. 安装Ubuntu Server 22.04（最小化安装）
  2. 配置静态IP: sudo nano /etc/netplan/01-config.yaml
  3. 配置DNS: sudo nano /etc/resolv.conf
  4. 安装nginx: sudo apt-get install nginx
  5. 配置开机自启: sudo systemctl enable nginx
  6. 配置rsyslog: sudo nano /etc/rsyslog.conf
  7. 配置logrotate: sudo nano /etc/logrotate.conf
