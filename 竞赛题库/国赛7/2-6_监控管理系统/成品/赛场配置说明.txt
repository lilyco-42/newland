====================================================
  监控管理系统 (竞赛任务 2-6) - 赛场配置说明
====================================================

一、如何修改摄像头配置
----------------------------------------------------
两种方式任选其一：

方式 1: 界面改（推荐, 无需记事本）
  双击运行 监控管理系统.exe
  → 点右上角「设置」按钮
  → 修改 摄像头 IP / 端口 / 用户名 / 密码 / RTSP 地址
  → 点「保存」→ 点「打开监控」重启取流

方式 2: 直接编辑 config.json（与本说明同目录）
  用记事本打开 config.json, 修改 camera 段:

    "camera": {
        "ip": "172.18.1.13",        ← 摄像头 IP(赛场现场用环境给的实际 IP)
        "port": 80,                 ← 摄像头 Web/HTTP 端口
        "user": "admin",            ← 登录用户名
        "pass": "",                 ← 登录密码(留空表示无密码)
        "rtsp_url": "rtsp://{ip}:554/stream2",   ← 视频流地址(stream2=子码流H264 流畅)
        ...
    }

  保存后重新打开 exe 生效。

二、config.json 字段说明
----------------------------------------------------
camera.ip        摄像头 IP 地址
camera.port      摄像头 HTTP 端口(默认 80)
camera.user      摄像头登录用户名(默认 admin)
camera.pass      摄像头登录密码(默认留空)
camera.rtsp_url  视频流地址, {ip} 会自动替换成 camera.ip
camera.stream_url/snapshot_url/ptz_url
                 部分旧式摄像头才需要, TP-LINK IPC 使用 RTSP+ONVIF, 可保持默认

三、画面出不来? 先按顺序查
----------------------------------------------------
1. 摄像头 IP 是否正确
   exe 同目录执行: ping <摄像头IP>
2. 视频端口是否通(554)
   设置里 RTSP 地址保持 rtsp://{ip}:554/stream2 (子码流)
   或换主码流:   rtsp://{ip}:554/stream1 (H265, 清晰但更重)
3. 登录不了(云台不可用)
   用户名/密码不对时画面仍能出(开启监控), 但云台会失败
4. 全部默认都不要动, 只需改 ip 一站

四、运行环境说明
----------------------------------------------------
本程序为绿色单目录程序(含运行库), 不依赖安装 Python。
请整个「成品」文件夹拷贝到赛场机器后运行,
exe 与 config.json 必须保持在同一目录。
